## 去程和回程分别怎么走

电信用户最省心。去程走 59.43 段 CN2 出境，经欧洲节点进伦敦机房，回程从英国本地电信节点直接上 CN2 回国。这条路径在多个测评的路由跟踪里一致，也是 AkkoCloud 全线主打的卖点。

联通去程走 AS4837，有测评记录显示是 AS4837 加 AS10099 直连法兰克福节点后再进伦敦。回程没有独立出口，借道电信的 CN2 链路回国，再落地到联通。对联通用户来说，回程质量等于搭了电信的车。

移动是变化最大的一块。去程走 CMI 直连欧洲，不同测评记录的后续承接线路并不一致，有写经德国节点到伦敦的，也有写香港 CMI 接 GTT 的，不给单一结论。回程在早期测评里还是 CN2 接驳移动，2024 年之后的记录显示已经改为 CMIN2 直连回国，这也是目前比较新的说法。移动用户如果在意回程，建议先用官方测试 IP `185.217.110.10` ping 一轮再决定。

延迟给区间而不是一个数：一份伦敦专项测评记录本地 ping 173ms、三网平均 167ms（电信 169ms、联通 167ms、移动 163ms）；另一份测评记录国内部分节点平均 192ms。差异来自测试节点分布和测试时段，不是线路本身变了。170ms 到 190ms 这个区间，对英国机房来说属于做过优化的水平。

## 带宽与硬件：500Mbps 能跑出多少

2022 年 5 月的一份详细测评记录了 speedtest 国内节点的成绩：上海上传 373.71Mbps、下载 211.77Mbps、延迟 176.48ms；南京 388.73 / 249.39 / 159.78ms；广州 346.71 / 167.23 / 171.17ms；东京 315.60 / 165.08 / 230.44ms；新加坡 373.43 / 230.89 / 185.80ms。首尔方向偏差明显，下载只有 28.34Mbps，延迟 279.60ms，韩国方向不要期待。

同一份测评的 iperf3 欧美方向数据：伦敦 386 / 253Mbps，巴黎 385 / 236Mbps，荷兰 385 / 212Mbps，纽约 372 / 177Mbps，洛杉矶 362 / 180Mbps。欧美区间基本能跑到标称带宽的七成以上，500Mbps 不是纸面数字。

本地单线程下载，有测评记录到 7.1MB/s，另一份记录写“最高 60Mbps 左右”。两个数看着差很远，实际是单线程与多线程、测试时段不同造成的，不用合成一个精确值。要判断自己这边能跑多少，拿官方 1GB 测试文件下一个最直接。

硬件层面，2022 年那台测试机是 Intel Broadwell 架构，单核 2.1GHz，731MB 内存，9.4GB 磁盘，KVM 虚拟化，已开 BBR。硬盘平均 I/O 645.7MB/s（三次分别 470 / 726 / 741MB/s），fio 的 4k 随机读写约 44MB/s（11.0k IOPS），64k 到 1m 的顺序读写稳定在 520 到 560MB/s。UnixBench 单核得分 649.3。这组数据放在年付 25 元/月的机器上属于正常偏好，建站和小服务够用，跑重负载的编译或数据库不合适。

另一份测评测的是 2 核 2GB、400Mbps 带宽的另一档配置，2 核 12 线程 UnixBench 约 694 分，硬盘 I/O 约 220MB/s。机型不同，不能和上面那台单核机器直接比分数。

IPv6 不支持，测评里明确写了当前主机跳过 IPv6 检测。

## 流媒体和 IP：能解锁什么，不能指望什么

2022 年 5 月 29 日的一份解锁测试结果：Netflix 可用（GB 区），YouTube Premium 可用（GB），Disney+ 可用但显示 US 区，Amazon Prime Video 可用（GB），HotStar 可用（GB）。英国本地服务里 BBC iPLAYER、ITV Hub、Channel 4、Sky Go、BritBox、Discovery+ UK 都通过，Channel 5 不通过。DAZN 不可用，Spotify 注册不可用，Steam 货币显示 GBP。

欧洲其他地区的服务基本没戏：Joyn、Sky DE、ZDF、Rai Play 都是 No，HBO Nordic、HBO GO Europe、HBO Spain、HBO Portugal 全部 Failed。想拿这台机器看德国或意大利本地内容，不用考虑。

这份数据距今有几年，流媒体平台的风控策略改过很多轮，只能当作参考，不能当现在的状态。真正影响体验的是 IP 属性：官方明确不保证原生 IP，测试 IP 也不代表你分到的网段，TOS 还写明了不允许以“不是原生 IP”为由申请退款。需要英国住宅 IP 的用户，这台机器从产品定位上就不匹配，得另找做英国家宽的服务商。

## 哪些人不该买这台

**必须要英国原生住宅 IP 的**。官方不保证原生，也不接受以此退款，需要家宽 IP 的场景得另找专门做英国家宽的服务商，别在这台上浪费时间。

**需要 IPv6 的**。当前不支持，测评里明确跳过了 IPv6 检测。

**不能接受严格退款政策的**。官方 TOS 整体偏严，明确写了不允许退款的情形。不确定就先买季付或月付，别一上来年付再想办法退。

**只想要最低延迟的**。伦敦物理距离摆在那，再怎么优化也追不上圣何塞，直接选美西。

下单前还有几件事确认一下：付款只支持支付宝，没有信用卡和 PayPal 通道；流量双向计费；客服工作时间是中午 12 点到晚上 10 点，工作时间内提交的工单承诺 24 小时内答复、48 小时内解决，非工作时间由值班人员处理，另有 Telegram 交流群可以问问题。
